I wanted to add some color to this site. Everything else here is black and
white, so the little picture next to each post is pretty much the only color
anywhere.

I thought about using AI generated images for those, but so far I've settled on
procedurally generated ones, which I prototyped with Claude. There aren't any
image files -- each picture gets drawn in code from the post itself when the
site builds, so every post ends up with its own.

You can play with the thing that draws them below. Type in whatever you want,
click around, and if you like one you can download it as a wallpaper.
